## Component prefixes

| Prefix | Long |
| --- | --- |
| `Ap_` | Application Software Component |
| `Sa_` | Sensor/Actuator Software Component |
| `Cd_` | Complex Device Driver |
| `IoHwAb` | Input/Output Hardware Abstraction |
| `Rte_` | Run-Time Environment generated interface |
| `SchM_` | Basic Software Scheduler Manager |
| Suffix `CM` | Current Mode (motor-control/drive context). Assumption: stated on each page that uses it. |
| Suffix `CF034B`, `CF09`, `CF10`, `CF12A` | Customer Feature numbers. |
| Codes `SF04B`, `SF05`, `SF31`, `SF35`, `SF38A`, `SF42`, `SF47`, `SF49A`, … | System Function numbers. |
| Codes `ES-01F`, `ES-04E`, `ES-35B`, `ES-36A`, `ES-55B`, `ES-56A`, `ES-57B`, … | Engineering Specification numbers. |
